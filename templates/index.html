    How should the tool work?
    What Automatic does for each file type
    • Word: real headings, title and language, contrast fixed with the standard colours, real bullet lists, table header rows, alt-text drafts, background pictures marked decorative, link check, logical heading order.
    • PowerPoint: title and language, contrast fixed (with a see-through backing for text on photos), alt-text drafts, background pictures marked decorative, link check, slide-title check.
    • PDF: tags added without changing the look (headings, lists, reading order, figures), title and language, contrast fixed, alt-text drafts, link check, logical heading order.
    • Scanned PDF: pages read with OCR (sideways pages too), the same-looking tagged scan, plus a reflowed text version that screen readers and Ally handle best.
    • Large files with many pictures: alt-text drafts are left for the review page so the batch finishes quickly.
    • Handwriting: not automatic (it's slow and needs a person to check it). Scanned PDFs get a “Transcribe handwriting” button on the results page.
